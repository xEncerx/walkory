# Walkory

Приложение для приёмки арендного жилья и составления отчёта о его состоянии.

- Создание приёмок для арендатора или арендодателя.
- Проверка помещений по готовым и собственным шаблонам.
- Добавление замечаний и фотографий.
- История приёмок и карточки объектов.
- Создание, просмотр и экспорт PDF-отчёта.

Приложение работает без интернета. Все данные хранятся на вашем устройстве.

Требуется Android 8.0 (API 26) или новее.

## Установка

Скачайте APK со [страницы последнего релиза](../../releases/latest) и установите его на устройство.

<details>
<summary>Сборка из исходников</summary>

Потребуются JDK 21 и Android SDK с платформой API 37. Откройте проект в Android Studio или настройте путь к SDK в `local.properties`.

В корне проекта выполните:

```bash
bash ./gradlew :app:assembleDebug
```

В Windows используйте `gradlew.bat :app:assembleDebug`. Готовый APK находится в `app/build/outputs/apk/debug/app-debug.apk`.

</details>
